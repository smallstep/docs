Profiles assigned in Intune reach new devices, but a device that has been running for a while does not receive them and shows no error.

## Cause

The device has been disconnected from Windows push notifications (WNS), which happens after a long uptime or a long sleep, so it receives no notification that new profiles are waiting.

## Fix

1. On the device, go to **Settings → Accounts → Access work or school**, expand the signed-in account, choose **Info**, and select **Sync**.
2. If the profiles still do not arrive, restart Windows to re-establish the channel.

Give it a minute after the sync for certificates to appear in the trust store.

## Check

The **Info** screen shows a recent successful sync, and the expected certificates are in the right stores: trusted roots and intermediates in the computer's root store, the client certificate in the personal store of the account the profile targets.
